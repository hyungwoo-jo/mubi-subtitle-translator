# Subtitle Translator for MUBI

Переводит существующие субтитры заранее и показывает перевод в исходное время реплики. Независимое расширение, проверенное с MUBI в Chrome для Windows; не является официальным продуктом MUBI. Edge может загрузить ту же папку, но воспроизведение в нём ещё не проверено.

## Установка

[ZIP / Releases](https://github.com/hyungwoo-jo/mubi-subtitle-translator/releases)

1. Скачайте ZIP релиза и распакуйте в постоянную папку. Откройте `chrome://extensions` (Edge: `edge://extensions`), включите режим разработчика и выберите **Загрузить распакованное расширение → extension/**.

2. Нажмите **Continue with ChatGPT** во всплывающем окне и на вкладке подключения. Пройдите официальный вход, разрешите использование плана, выберите и подтвердите модель.

3. В настройках выберите язык интерфейса и язык перевода. Включите исходные субтитры MUBI, согласитесь на обработку и запустите расширение на сайте. Обновите страницу видео.

4. Не закрывайте вкладку подключения во время просмотра. Python, Codex CLI и локальный помощник не нужны. Токены хранятся только в памяти вкладки. Для отзыва доступа выйдите из аккаунта.

## Перевод и конфиденциальность

При наличии загружается весь файл субтитров; перевод готовится пакетами максимум на пять минут вперёд. При запуске и переходе за подготовленный интервал возможна задержка. Распознавание видимого текста может работать медленнее.

По умолчанию интерфейс английский, в настройках доступны 16 языков. Язык перевода задаётся отдельно. Расширение бесплатно, но действуют ограничения плана ChatGPT. Субтитры, контекст и настройки перевода передаются напрямую OpenAI.

Для установки с GitHub не нужен аккаунт разработчика магазина. В магазин расширение ещё не отправлено. Ollama и Codex CLI — дополнительные режимы, требующие отдельной установки.
